# Rollback / Recovery Receipt

| Field | Value |
| --- | --- |
| Task / phase | ... |
| Evidence type | rollback / recovery |
| Exact result SHA or tree | ... |
| Trigger | ... |
| Command or procedure | ... |
| Result | PASS / FAIL / NOT_RUN / BLOCKED / NOT_APPLICABLE |
| External evidence reference | ... |
| NOT_APPLICABLE rationale / boundary / reviewer confirmation | ... |
| Limitation | ... |

For a NOT_APPLICABLE result, record the rationale, applicability boundary, and reviewer confirmation. It is invalid where the task or Gate requires a rollback or recovery rehearsal.
